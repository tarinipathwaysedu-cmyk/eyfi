Built as a single self-contained HTML/CSS/JS file with no framework or build step. It's an interactive top-down excavator that climbs a track and breaks the ice off each reward — playable three ways: an auto run, a drag-steer cockpit, or the registration slider — with SVG-turbulence frost, canvas particle effects, and synthesized Web Audio sound (engine, servo, ice-crack, fanfare). Designed and built iteratively with Claude (Anthropic). Deployed on Cloudfare.
